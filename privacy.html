Privacy

This game records how each match plays, using PostHog and Supabase, and never who you are.

What is recorded

  • How you play, as events sent to PostHog: the session starting, the title screen, the scoring rules opened, each match and level starting and ending, each ball lost, each pause, and each of Jev's choices in brief. Each event carries your screen size, whether you use a mouse or touch, the level, the score and the time into the level.
  • The match record, sent to the game server and kept in Supabase: every question Jev was asked with the board it was shown, every launch and lost ball, how much each side had cleared once a second, and each level's result.
  • One anonymous id: a random id PostHog makes on your first visit and keeps in this browser's local storage, so a returning player counts once. It is linked to nothing, never names you, and never goes into the match record. Clearing this site's data or opting out ends it.

What is never recorded

  • Your IP address. PostHog's IP capture is off, and the server writes none to Supabase. To share out the day's Jev calls fairly, the server reads your address in memory for the current day and never writes it down.
  • Names, emails or accounts. The game has none and takes no typed text.
  • A fingerprint or a profile of you. PostHog keeps no person profiles.
  • A recording of your screen. Session replay is off.
  • Debug play, or a match the stand-in plays in Jev's place.

Who keeps it, and where

  • PostHog keeps the events. Region pending: the PostHog project is not set up yet. US Cloud is the plan.
  • Supabase keeps the match record, in West US (Oregon). Pending: the Supabase project is not set up yet. Until it is, the game server keeps match records as files on its own disk.
  • Only the game's maker reads either, through PostHog's and Supabase's own sign-ins.

How long

  • PostHog events: as long as PostHog's free plan keeps them.
  • Full match records: 90 days. A weekly job then deletes them, keeping only each match's summary: when it was played, the final score and a count of Jev's choices.
  • A monthly copy of the records, made before that deletion, stays on the game's maker's own computer as its backup.

How to opt out

  • Choose Opt out beside the notice on the title screen. This browser then sends no events and no match record, and the anonymous id ends. The game plays exactly the same. The browser remembers the choice, and the same spot offers Opt back in.
  • Turn on Do Not Track in your browser. The game treats it as the same opt-out.
  • Clearing this site's data forgets the choice along with the id, so opt out again afterwards.
