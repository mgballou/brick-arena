Live game / keyboard controls

Play against Jev

The game is one match against live Jev. You play the left board with the arrow keys; Jev plays the right through the dev server's forwarder. There is no bot mode. The local stand-in is available only in debug mode.

Run locally

pnpm install
printf '%s\n' '<your TypeSafe key>' > ~/.jev-key
chmod 600 ~/.jev-key
pnpm dev

Use Node 24. The dev server reads ~/.jev-key once at startup and forwards Jev's calls; the browser never sees the key. Open http://localhost:5173 and press Enter. Left and Right move your paddle; Space or Up serves after a lost ball. P pauses, H shows scoring, and M mutes.

Check the live link

pnpm smoke

Makes one live call and prints its status, latency, and Jev's choice. It reads the key from ~/.jev-key.

Jev's seat / one typed choice

How Jev is asked to play

The game sends one closed question at a time: target, chase, or track. Jev returns one choice from that question's listed options.

target offers landing, aim, angle-left, or angle-right. Each named choice maps to a paddle position; Jev never sends paddle arithmetic.

chase offers the falling power-ups by id, or none; track asks which ball to play.

An answer outside the offered options, or one that is not a choice, is rejected.

Key path

~/.jev-key

The dev server reads this file once when it starts. Its forwarder adds the key to Jev's request, so the browser never receives it. The hosted page uses the host's JEV_API_KEY secret instead; that environment route is for the server, not local browser play.

When Jev is slow or unavailable

The board keeps playing Jev's last answer while a call is pending. An answer that arrives after two seconds is late and changes nothing; three late calls in a row pause the match until Jev is back. When Jev cannot answer, the page says the game is down and shows no board.

Debug mode: start the local stub and use a dummy key file with VITE_DEBUG=1 to allow the stand-in to play. The screen shows a debug banner; this is not a live Jev match. The README has the complete commands.
